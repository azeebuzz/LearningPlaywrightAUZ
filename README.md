# LearningPlaywright

This repository is a learning workspace for JavaScript, TypeScript, and Playwright concepts. It contains chapter-wise practice files, task exercises, interview-style code, and mini test cases.

## Repository Structure

### Core learning chapters
- **chapter_01_Basics/**: JavaScript basics and setup checks.
- **chapter_02_Java_Concepts/**: Java concepts, identifiers, variables, scope, and hoisting.
- **chapter_03_Identifiers_Literal_Operators_Statements/**: identifiers, literals, operators, and statements.
- **chapter_04_Operators/**: arithmetic, comparison, logical, and type operators.
- **chapter_05_Statements/**: conditionals and decision-making exercises.
- **chapter_06_Switch_statements.js/**: switch-case examples and bug-based exercises.
- **chapter_07_Loops/**: for, while, do-while, and loop practice files.
- **chapter_08_Arrays/**: arrays, methods, sorting, deep/shallow copy, and destructuring.
- **chapter_09_Functions/**: function basics, callbacks, and function patterns.
- **chapter_10_Strings/**: string operations and manipulations.
- **chapter_11_Objects/**: object creation, methods, getter/setter, spread, and destructuring.
- **chapter_12_MultidArray/**: multidimensional arrays and pattern exercises.
- **chapter_13_Callback/**: callback concepts, callback hell, and async flow practice.
- **chapter_14_Promise/**: Promise APIs, catch/finally, all/race, and real examples.
- **chapter_15_Async_Await/**: async/await patterns and real-life async exercises.
- **chapter_16_OOps/**: classes, objects, encapsulation, and export/import patterns.
- **chapter_17_OOPs_Inheritance/**: inheritance, overriding, and class-based design examples.
- **chapter_18_Typescript/**: TypeScript basics and type fundamentals.
- **chapter_19_Typescript_Interface/**: interfaces, real-world contracts, and Page Object style patterns.
- **chapter_20_Typescript_ENUM/**: enums, practical examples, and browser selection patterns.

### Practice and task folders
- **Tasks/**: daily/weekly coding tasks grouped by date or topic.
- **Test_Feb_28th/**: mini practice and validation exercises.
- **JS Practice/**: personal practice scripts and quick experiments.

### Project config
- **package.json**: project dependencies and scripts.
- **tsconfig.json**: TypeScript configuration used for local validation.
- **.gitignore**: excludes generated and local-only folders like node_modules, logs, and practice folders.

## Ignored folders
The following are intentionally ignored by Git and are not meant to be part of the main repository history:
- **node_modules/**
- **JS Practice/**
- **Test_Feb_28th/**
- **.playwright-cli/**
- **dist/**
- log and local environment files

This helps keep the repository focused on learning files rather than generated or local tooling output.

## Getting Started
1. Clone the repository.
2. Open the chapter or task folder you want to study.
3. Run the JavaScript or TypeScript examples with Node.js or your preferred environment.

## Notes
This repo is mainly for learning and experimentation. Some folders are intentionally kept lightweight and may be added progressively over time.
